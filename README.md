## 📖 Overview

The **Secure Banking Transaction Portal** is an end-to-end **DevSecOps demonstration project** built to showcase secure software delivery, containerization, Kubernetes orchestration, GitOps deployment, automated security scanning, and cloud-native monitoring.

The project simulates a banking application while implementing modern DevSecOps practices throughout the Software Development Life Cycle (SDLC).

---

## Objectives

- Build an end-to-end DevSecOps pipeline.
- Automate code quality and security checks.
- Containerize and deploy a Flask application to Kubernetes.
- Implement GitOps using Argo CD.
- Monitor infrastructure and applications with Prometheus and Grafana.
- Demonstrate secure software delivery using industry-standard open-source tools.
